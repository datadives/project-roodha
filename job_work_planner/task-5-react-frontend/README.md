# Frontend — Job Work Planner

## Overview
This is the React frontend for the Job Work Planner project. It uses Vite for fast builds and Tailwind CSS for styling.

## Structure
- `src/` — Main source code
  - `components/` — React components
  - `context/`, `hooks/`, `lib/`, `pages/`, `schemas/`, `tests/` — App logic and utilities
- `public/` — Static assets

## Setup
1. Install dependencies: `npm install`
2. Copy `.env.example` to `.env` and fill in required variables
3. Start the dev server: `npm run dev`

## Notes
- Do not commit `node_modules`, `.env`, or build files.
- See the root `README.md` for more info.
