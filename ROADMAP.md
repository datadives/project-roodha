# PROJECT ROODHA: PRODUCT ROADMAP
## Multi-Stage Industrial Evolution

### STAGE 1: THE FOUNDATION (v1.0 - v1.2) - [COMPLETED]
- Core RESTful API (FastAPI) & PostgreSQL Schema.
- Basic Job & Part Master management.
- Initial Shop Floor Dashboard.

### STAGE 2: INDUSTRIAL HARDENING (v1.5 - Current) - [STABILIZED]
- **Multi-Tenancy**: Database isolation via RDS Row-Level Security (RLS).
- **Security**: AWS Cognito JWT Integration & Role-Based Access Control (RBAC).
- **Resilience**: 10s API timeouts, automatic retries, and offline-aware fetching.
- **UI/UX**: JetBrains Mono for numeric precision, Safety Orange aesthetics.
- **Production Specs**: Formal documentation of Backend/Frontend architectures.

### STAGE 3: INTELLIGENCE & SCALE (v2.0 - Upcoming)
- **AI Prompt Bot**: Natural language interface for production managers to query "Which jobs are late?".
- **Predictive Maintenance**: Integration with machine sensor data to predict downtime.
- **WhatsApp Integration**: Automated alerts to shop floor supervisors for delayed jobs.
- **Multi-Plant Support**: Advanced tenant hierarchy for corporate entities with multiple factory locations.
